# A systematic review on quantifying the impact of algorithm artifacts as outputs of artificial intelligence research

This repository holds the data and documentation for a systematic literature review on how the impact of an algorithm can be quantified to complement the citation-based measure of its paper. The review follows PRISMA.

## Scope

The review analyzes 47 primary studies that treat an algorithm, or its materialization as software or code, either as the entity being measured or as the mechanism explaining a measured impact. Each study was read in full and coded against five research questions.

| RQ | Topic |
|----|-------|
| RQ1 | Forms an algorithm takes once it leaves the paper |
| RQ2 | Data sources that make those forms observable |
| RQ3 | Methods used to quantify impact, organized as attention, adoption, and merit |
| RQ4 | Biases and gaming risks of these methods |
| RQ5 | Decisions that innovators, adopters, and funders can support |

## Screening and Coding

Two raters, both authors of the review, performed the selection, and their agreement on whether to include a paper was almost perfect (Cohen's kappa = 0.850). Disagreements were resolved by discussion. The coding sheet records, for each study, the algorithm form, the data source, the measure family, the impact axis, the reported biases, and the stakeholder benefit.
